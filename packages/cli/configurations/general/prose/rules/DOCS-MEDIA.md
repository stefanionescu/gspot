# Documentation Media

Match instructions to the current interface. Reproduce control labels exactly and name the
control by its label. Color and position can change. A screenshot supplements the procedure; it cannot
replace instructions available to readers who cannot see it.

## Media ownership

Keep illustrations with documentation and preserve their editable source and license. Use a
screenshot for a real interface, a diagram for a relationship, and a chart for data. Add media
only when it explains something text cannot show clearly. Report stale media when behavior
or labels change.

A video needs captions and a transcript for information absent from the page. Keep the complete
procedure in text. Do not embed a tracker or commit video without the project's asset workflow.

## Accessibility

Meaningful images explain their purpose and relevant state in context. A complex diagram has its
full relationship in nearby text. Decorative images use empty alt text. Never rely on color alone
for a state or instruction.

## Presentation choices

<!-- level: all -->

Keep diagrams small and give equal concepts equal shapes. Prefer editable, versioned diagrams
where the renderer supports them. Use stable descriptive names rather than numbered images.
Keyboard alternatives and platform variants keep a consistent order.

## References

See [W3C image guidance](https://www.w3.org/WAI/tutorials/images/)
and [Google interface guidance](https://developers.google.com/style/ui-elements).
