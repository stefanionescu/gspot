# Concept Template

Requirements about vocabulary, architecture, naming, documentation coverage, declaration
order, API style, and complexity apply at `all` or when the project explicitly opts into
them. Correctness, security, accessibility, type safety, routine formatting, and declared
project contracts apply at both levels.

Template. Remove sections that do not apply. Do not publish empty headings or placeholder
prose.

```markdown
# CONCEPT_NAME

Define the concept and explain why it matters.

## How it works

Describe the major parts and relationships.

## Boundaries and ownership

Describe responsibilities and dependency direction.

## Constraints

- CONSTRAINT
- CONSTRAINT

## Related tasks

- [DESCRIPTIVE_TASK](RELATIVE_LINK)
```
