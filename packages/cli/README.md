# gspot

gspot lints AI-generated code and writes rules for AI coding agents.

## Install

Commit your work, then run:

```sh
npm install --save-dev --save-exact @gspothq/cli
git add package.json package-lock.json
git commit -m "build: Add gspot"
npx gspot init
npx gspot install
npx gspot check
```

The [install guide](https://generativespotting.com/guides/install/) covers other package managers and mise. The
[gspot guides and reference](https://generativespotting.com/) cover everything else.
