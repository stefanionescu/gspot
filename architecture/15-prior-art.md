# Prior Art

This document decides what gspot copies from tools people already trust, what it does
differently, and which libraries it reuses instead of writing its own. It exists so nobody shops
twice. A row here is a recorded choice; a new choice supersedes it with a new row and a decision
in [14-decisions.md](14-decisions.md).

## Tools gspot learns from

| Tool                                                                                                                               | What it does well                                                                                                                                                                                                                                                                             | What gspot copies                                                                                                                                  | What gspot does differently                                                                                                                                                                                                                                                                     |
| ---------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [qlty](https://github.com/qltysh/qlty)                                                                                             | The closest prior art. `qlty init` reads the repository and enables plugins; `qlty check`, `qlty fmt`, `qlty smells`; sixty-plus linter plugins with pinned versions in `.qlty/qlty.toml`; docs ship an `llms.txt` and a page on working with AI agents                                       | The command shape; the `llms.txt` file and the agents page in gspot's docs                                                                         | gspot never downloads tools (D-06); it writes real configuration at the paths editors read; it adds the slop rules, the naming engine and the agent rule files, which qlty has no equivalent of. qlty's Fair Source license (BSL 1.1) forbids competing use, so it is never a dependency (D-56) |
| [Trunk Check](https://docs.trunk.io/references/cli/configuration)                                                                  | `.trunk/trunk.yaml` pins the CLI and every linter; `trunk check` defaults to files changed against upstream                                                                                                                                                                                   | One version pins everything (D-06, D-49)                                                                                                           | `check` runs the whole tree by default; `--since <ref>` is the pull-request form. Trunk is closed source and downloads its tools                                                                                                                                                                |
| [pre-commit](https://github.com/pre-commit/pre-commit.com/blob/main/sections/advanced.md) and [prek](https://github.com/j178/prek) | One config with pinned hook revisions; `run --all-files`; `autoupdate --freeze`; the [identify](https://github.com/pre-commit/identify) library tags files (`shell`, `python`, `executable`) from extension, shebang, executable bit and content, so hooks select by tag instead of extension | Preset claims may name tags as well as extensions, computed the way identify does                                                                  | gspot writes the tools' configuration and owns the rules; pre-commit only runs hooks                                                                                                                                                                                                            |
| [Biome](https://biomejs.dev/guides/migrate-eslint-prettier/)                                                                       | `biome migrate eslint` reads an ESLint config through rule metadata; `biome explain <rule>` says why a rule exists and shows a snippet; the npm package is a thin launcher over per-platform `optionalDependencies`                                                                           | `explain` (D-50); the per-platform npm packages (D-52)                                                                                             | Takeover replaces rather than migrates (D-46), because the point is to adopt the shipped policy                                                                                                                                                                                                 |
| [Ruff](https://docs.astral.sh/ruff/linter/)                                                                                        | `ruff rule <code> --output-format json` explains a rule; `--output-format`; `--statistics`; unsafe fixes are marked; a `help:` line under every finding                                                                                                                                       | The `help:` line under every finding; `ruff rule` as the source for `explain python/ruff <code>`                                                   | none; Ruff is a tool gspot drives                                                                                                                                                                                                                                                               |
| [uv](https://docs.astral.sh/uv/) and [mise](https://mise.jdx.dev/dev-tools/backends/ubi.html)                                      | Single binary; `doctor`; `mise.toml` with `conf.d/` merging; `github:` installs any GitHub-release binary; settings validated through a published JSON schema                                                                                                                                 | The runner integration, the pin, `doctor`, and a published `gspot.schema.json` (D-53)                                                              | none                                                                                                                                                                                                                                                                                            |
| [gh](https://cli.github.com/) and [cargo](https://doc.rust-lang.org/cargo/)                                                        | `--json` everywhere; stable exit codes; `cargo --message-format json`                                                                                                                                                                                                                         | `--json` is global                                                                                                                                 | no `--jq`; a person has `jq`                                                                                                                                                                                                                                                                    |
| [lint-staged](https://github.com/lint-staged/lint-staged)                                                                          | Hides unstaged changes behind a stash and restores them; `--fail-on-changes`; documents every failure mode of the stash                                                                                                                                                                       | The honest line about working-tree content; fixes in a hook never stage themselves                                                                 | gspot reads working-tree content and says so instead of stashing ([10-hooks-ci-runners.md](10-hooks-ci-runners.md))                                                                                                                                                                             |
| [treefmt](https://github.com/numtide/treefmt)                                                                                      | One `treefmt.toml`; one formatter per file; parallel; a cache on file metadata                                                                                                                                                                                                                | Confirms the tool runner in [05-engines.md](05-engines.md)                                                                                         | gspot's cache key is the content hash plus tool version plus configuration hash                                                                                                                                                                                                                 |
| [projen](https://github.com/projen/projen/blob/main/ARCHITECTURE.md)                                                               | Generated files carry a magic header, are read-only on disk, and an anti-tamper check runs in CI; synthesis finds generated files by their header, not a stored list                                                                                                                          | `integrity/generated-drift` finds generated files by their mark; generated files are written read-only where the platform allows                   | gspot generates tool configuration, not the project                                                                                                                                                                                                                                             |
| [MegaLinter](https://megalinter.io/latest/descriptors/yaml_yamllint/)                                                              | One YAML descriptor per linter: install, command line, config file, output format, file types; over a hundred of them                                                                                                                                                                         | The descriptors are the reference when a preset manifest is written: every tool gspot ships has one to read the command line and output shape from | gspot does not run in Docker and ships a curated set, not every linter                                                                                                                                                                                                                          |
| [clig.dev](https://clig.dev/)                                                                                                      | The checklist for human-first command lines                                                                                                                                                                                                                                                   | The Conventions section of [02-cli.md](02-cli.md)                                                                                                  | none                                                                                                                                                                                                                                                                                            |

## Libraries gspot reuses

Each row names a job the design once implied gspot writes itself, and the library that does
it. [12-repository-layout.md](12-repository-layout.md) lists the same libraries by job.

| Job                                       | Library                                                                                                                                                                                                                                   | What it replaces                                                                                        |
| ----------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| npm distribution                          | per-platform packages as `optionalDependencies` with `os` and `cpu` fields and a thin `bin` launcher, the pattern of `@biomejs/biome` and [`@ast-grep/cli`](https://www.npmjs.com/package/@ast-grep/cli)                                  | a wrapper that downloads the binary at install, which fails behind proxies and under `--ignore-scripts` |
| Writing `gspot.toml` with comments intact | [`@decimalturn/toml-patch`](https://github.com/DecimalTurn/toml-patch): TOML 1.1, `patch()` and `TomlDocument`, comments travel with the entry they belong to                                                                             | a line-based appender                                                                                   |
| Package manager detection                 | [`nypm`](https://github.com/unjs/nypm) (`detectPackageManager`)                                                                                                                                                                           | Reads the package manager from the repository.                                                          |
| `.gitignore` semantics without git        | [`globby`](https://www.npmjs.com/package/globby) with `gitignore: true`                                                                                                                                                                   | A hand-written matcher.                                                                                 |
| Naming a language gspot has no preset for | [`linguist-languages`](https://www.npmjs.com/package/linguist-languages), GitHub Linguist's data as a package                                                                                                                             | a hand-kept extension table                                                                             |
| SARIF                                     | [`node-sarif-builder`](https://github.com/nvuillam/node-sarif-builder)                                                                                                                                                                    | a hand-written writer                                                                                   |
| Shell completions                         | [`@bomb.sh/tab`](https://github.com/bombshell-dev/tab) with its commander adapter; used by Wrangler, Nuxt, Astro, and Vitest                                                                                                              | a `completion` command written by hand, which is why it sat in v1.1                                     |
| JSON schema for `gspot.toml`              | zod v4 [`z.toJSONSchema`](https://zod.dev/json-schema); `zod-to-json-schema` is unmaintained since November 2025                                                                                                                          | nothing; adds editor validation through SchemaStore                                                     |
| Preset templates                          | [`eta`](https://eta.js.org/)                                                                                                                                                                                                              | a placeholder renderer of gspot's own                                                                   |
| Command parsing and help                  | [commander](https://github.com/tj/commander.js)                                                                                                                                                                                           | the most used option; its help text is the command reference                                            |
| Questions at `init` and `upgrade`         | [`@clack/prompts`](https://github.com/bombshell-dev/clack)                                                                                                                                                                                | any other prompt library                                                                                |
| Parsing for the engines                   | [`web-tree-sitter`](https://github.com/tree-sitter/tree-sitter), [`libpg-query`](https://github.com/pganalyze/libpg_query) WASM, the [ast-grep CLI](https://ast-grep.github.io/)                                                          | a parser of any kind                                                                                    |
| Identifier splitting                      | [`scule`](https://github.com/unjs/scule)                                                                                                                                                                                                  | the naming engine's case splitter                                                                       |
| Workspace discovery                       | [`@manypkg/get-packages`](https://www.npmjs.com/package/@manypkg/get-packages)                                                                                                                                                            | reading `workspaces`, `pnpm-workspace.yaml`, Lerna, and Rush by hand                                    |
| JSON with comments, YAML, `package.json`  | [`jsonc-parser`](https://github.com/microsoft/node-jsonc-parser), [`yaml`](https://github.com/eemeli/yaml), [`@npmcli/package-json`](https://www.npmjs.com/package/@npmcli/package-json)                                                  | writers that lose comments or indentation                                                               |
| License expressions                       | [`spdx-expression-parse`](https://www.npmjs.com/package/spdx-expression-parse), [`spdx-satisfies`](https://www.npmjs.com/package/spdx-satisfies)                                                                                          | string comparison of license names                                                                      |
| Markdown structure                        | `mdast-util-from-markdown`, `mdast-util-to-string`, and `unist-util-visit`                                                                                                                                                                | Syntax trees for headings, examples, README structure, and path exclusions.                             |
| CSS structure and selectors               | `postcss`, `postcss-scss`, and `postcss-selector-parser`                                                                                                                                                                                  | Stylesheet rules and decoded class names.                                                               |
| Diffs                                     | [`diff`](https://www.npmjs.com/package/diff)                                                                                                                                                                                              | a diff printer                                                                                          |
| Concurrency                               | [`p-limit`](https://www.npmjs.com/package/p-limit)                                                                                                                                                                                        | a queue                                                                                                 |
| Messages on stderr                        | [`consola`](https://github.com/unjs/consola)                                                                                                                                                                                              | a logger with levels and TTY detection                                                                  |
| Windows spawning                          | [`cross-spawn`](https://www.npmjs.com/package/cross-spawn)                                                                                                                                                                                | `.cmd` shim handling                                                                                    |
| Newer-version lookup                      | [`latest-version`](https://www.npmjs.com/package/latest-version)                                                                                                                                                                          | a registry client                                                                                       |
| Release                                   | [changesets](https://github.com/changesets/changesets), [`actions/attest`](https://github.com/actions/attest-build-provenance), `softprops/action-gh-release`, [`verdaccio`](https://github.com/verdaccio/verdaccio) for the publish test | release scripts                                                                                         |
| Docs site                                 | [Starlight](https://starlight.astro.build/) with [`starlight-llms-txt`](https://github.com/delucis/starlight-llms-txt)                                                                                                                    | a site generator and an `llms.txt` writer                                                               |

## Considered and not adopted

| Candidate                                                            | For                                                        | Why not                                                                                                                                                                                                          |
| -------------------------------------------------------------------- | ---------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [dependency-cruiser](https://github.com/sverweij/dependency-cruiser) | JavaScript and TypeScript import rules, cycles, boundaries | Maintained and thorough, but it runs as its own command with no editor feedback; D-02 chose the ESLint plugin so the editor shows the rule. It is the fallback if `eslint-plugin-boundaries` proves insufficient |
| [tach](https://github.com/tach-org/tach)                             | Python module boundaries                                   | import-linter already covers the contracts and lives in `pyproject.toml`; two tools for one job breaks D-28                                                                                                      |
| [ls-lint](https://ls-lint.org/)                                      | File and directory case rules                              | The naming engine already extracts every name for banned-term matching; a second tool would do half the check                                                                                                    |
| [Stricli](https://bloomberg.github.io/stricli/)                      | Command framework                                          | Typed, zero dependencies, autocomplete built in, but bash-only completions and a small community. commander stays                                                                                                |
| [Clipanion](https://github.com/arcanis/clipanion)                    | Command framework                                          | v4 has sat at release candidate since 2024                                                                                                                                                                       |
| [oclif](https://oclif.io/)                                           | Command framework with installers and an update command    | About 50 MB of dependencies, Node-only, unproven under `bun build --compile`                                                                                                                                     |
| [qlty](https://github.com/qltysh/qlty) as an engine                  | Running the linters                                        | Fair Source license; downloads tools itself                                                                                                                                                                      |
| [MegaLinter](https://megalinter.io/) as an engine                    | Running the linters                                        | Docker-only; runs everything rather than a curated set                                                                                                                                                           |
| [linguist-js](https://github.com/Nixinova/LinguistJS)                | Language detection over the tree                           | Fetches Linguist data at run time; gspot uses the `linguist-languages` data package offline instead                                                                                                              |
