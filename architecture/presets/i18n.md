# `i18n`

Kind: library. Requires: typescript or javascript.

## Detects

`next-intl`, `i18next`, `react-intl` or `@formatjs/intl` in dependencies.

## Generated configuration

The ESLint config gains `eslint-plugin-i18next` `no-literal-string` over JSX text and the
attributes `alt`, `aria-label`, `placeholder`, `title`.

## Checks

| Id                  | Stage  | Command                                                                                                                                                                                                                                     |
| ------------------- | ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `typescript/eslint` | commit | with `i18next/no-literal-string`                                                                                                                                                                                                            |
| `integrity/locales` | push   | every catalog parses as ICU MessageFormat; no empty message; keys contain no dots; every locale has every key the base locale has and no extra; every key is used (through the type checker for next-intl, through a string scan otherwise) |

## Settings

`tools.i18n.catalogs` (directory, base locale, format `json` or `po`), `tools.i18n.translator`
(the package whose translator call is traced, default detected).

## Rule files

`shared/i18n/I18N.md`; `library/next-intl/NEXTINTL.md` when `next-intl` is a dependency.
