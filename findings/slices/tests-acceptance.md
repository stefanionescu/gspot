# Tests: Acceptance

All 49 files in `tests/acceptance` were read in full: 11 in `cli` and 38 in `kits`. 43 files have at least one new finding, listed in 43 rows. The main patterns are these:

- Test names fake a describe level with " > " between the parts, and about 25 names and headers still call a kit a "configuration."
- Tests rebuild what the harness already has: module links, bin paths, the `gspot` launcher, `installSandbox`, `plantedCases`, `gitOutput`, and the `TYPO` table.
- Setup steps and Git calls ignore their exit codes.
- Planted manifests hard-code package versions (one has already drifted), and six strict `tsconfig` copies exist beyond the four the first audit names.
- Some tests disappear silently on other platforms, or assert only a platform skip note on Windows.
- Some `tools` lists name tools that no case runs, and some assertions pin a tool's own message text.
