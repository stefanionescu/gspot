# Commands and the Entry Point

The review read all 36 files in full: 35 under `packages/cli/src/commands` and `main.ts`. 34 have new findings. The main patterns are these:

- Failures print in about nine different JSON shapes, and plain `Error`s get the misleading prefix `gspot did not run:`.
- Several user texts and help lines promise what the code does not do.
- `init` previews one plan and writes another.
- Wording left over from older designs remains ("configuration" for kit, "plan," "content," and terms that `gspot.toml` bans).

- In the same `main.ts` line, the stale part is the comment in `program.ts:71-72` that cites tests. This is a precision note, not a wrong finding.
- The `RUNNING_VERSION` row (`program.ts:22` and four more files): the count is correct. The fix can be smaller, as the table above shows.
