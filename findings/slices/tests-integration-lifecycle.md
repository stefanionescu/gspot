# Tests: Lifecycle and Repository Integration Tests

The review read all 36 files in full, and 34 of them have at least one new finding (49 rows; paths below are relative to `tests/integration/cli/`). The main patterns are these:

- Setup is copied where a harness helper or constant already exists (Git calls, init options, `emitAll`, the crash child program).
- Some assertions cannot fail (unchanged bytes after a read-only call, a pin that init already wrote, an upstream placed on the root commit).
- Refusals are checked with no message or with a pattern that fits every row.
- Several file names describe only part of their tests, and the ownership installation tests are spread over three files.
