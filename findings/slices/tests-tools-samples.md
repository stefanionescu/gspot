# Tests: Native-Tool Tests and Samples

All 50 files were read in full: 38 in `tests/tools` and 12 in `tests/samples`. 38 files have at least one new finding, listed in 74 rows. No file in `tests/tools` imports a sample. The main patterns are these:

- Eleven files register tests inside `if (...)`, so a skipped test leaves no trace in the run.
- Several assertions cannot fail through gspot. They check files that nothing writes, or a value that is constant in most rows.
- Names promise more than the body tests, or name the tool when gspot does the work.
- Tests copy what a harness helper, a manifest pin, or `policyOf` already owns: venv paths, commits, tool versions, and policy text.
- The sample sizes and names are unexplained, and two sample names collide with source constants that mean something else.
