# Repository and Platform

The review read all 28 files: 15 in `packages/cli/src/repository` and 13 in `packages/cli/src/platform`. 23 of them have new findings. The main patterns are dead data and parameters, and doc comments that say something the code does not do. The slice also has real bugs in edge cases: `.gitattributes` overrides, lock races, a Git error with no text, and one Git process per remote branch on every push. Finally, `Root` refuses links in user folders, so a symlinked `.cursor/rules` folder stops `init` and `doctor`.
