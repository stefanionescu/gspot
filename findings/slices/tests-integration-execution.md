# Tests: Execution Integration Tests

- Several assertions pass for the wrong reason. The cause is a level that turns the check off, a file order the file system already gives, or a working directory that equals the session root.
- Many files hold tests of check engines, repository code, or the xcode kit instead of execution.
- Options and fixtures change nothing (`isDryRun` without `fix`, dead lookups, unused planted files), and seven `if (...) test(...)` blocks hide tests without a skip report.
