# Generation and Lifecycle

The review read all 49 files in `packages/cli/src/generation` (22) and `packages/cli/src/lifecycle` (27). 38 have findings that the first audit does not list. The main patterns are these:

- Kit features that no shipped kit uses: pointer `merge` and `copy`, and with them the JSON and YAML merge editors.
- Fallbacks and defaults that copy kit data or are never used.
- Small rules written three or four times: nested scopes, policy-table layering, UTF-8 decoding, the "block still in place" test, and removing `reason`.
- Error messages that name no file or use internal words.
- Doc comments that are wrong.

Paths are relative to `packages/cli/src/` unless they start with `kits/` or `tests/`.
