# Policy

The review read all 23 files in `packages/cli/src/policy` in full. 21 of them have findings that the first audit does not list. The main patterns are these:

- Reason-fix commands add a second entry instead of fixing the flagged one.
- Two code paths work out some values in different ways (per-language limits, `[format]`, rule-off refusal).
- Validation has gaps (keys `writtenKeys` never lists, scope paths left out of Ruff problems).
- Some doc comments are wrong or garbled.
- Nothing reads some parameters and fields.
