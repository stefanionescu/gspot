# Docs, Sentence by Sentence

The review read 314 pages in full: 17 guides, the 404 page, the homepage, 5 READMEs, and 290 generated reference pages (13 command, 53 kit, 199 check, 22 plugin, settings). It also read the policy file page in part. New findings cover 16 of the 17 guides, 4 of the 5 READMEs, the homepage, and every generator. Most of the 199 check pages share only the template problems; 14 have their own.

Five patterns stand out. A help line or doc example does not work as written (`gspot explain <rule>`, `[[naming.rules]]`, the `gspot set` line that `explain` prints). Pages promise behavior that only level `all` gives. Two pages contradict each other about scope paths and profiles. Generated text shows internal words such as "governs," "renders," "kit owner," and "Defect and correction." The plugin pages print raw JSON schemas, with no description of any option.
