# Kits: Python, Swift, Bash, and SQL

The review read all 16 files in full: 4 manifests, 9 templates, and 3 ast-grep rule files. 15 of them have new findings. The review ran each tool against small samples in the scratchpad. The Python tools were Ruff 0.16.8, basedpyright, deptry, vulture 2.16, and pydoclint 0.9.1. The Swift tools were SwiftFormat 0.61.1 and SwiftLint 0.63.2. The others were ShellCheck 0.11.0, shfmt 3.12.0, sqlfluff 4.3.0, Semgrep, and ast-grep.

The main patterns are these. The generated configurations break working code or fight each other: Ruff fixes ignore `requires-python`, and SwiftFormat output fails SwiftLint in 4 rules. Python tools run outside the project's environment. Several rules and settings do nothing. Shell scripts that use `sh` are linted as Bash. Some Semgrep rules miss real leaks and report harmless code.
