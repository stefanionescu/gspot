# Checks: Database, Framework, Library, Platform, Tool, and the Registry

The review read all 37 files in this slice. Of these, 34 have new findings.

The serious ones are correctness bugs that no earlier row covers. Postgres compares migration versions as strings and reads down migrations as forward changes. Checks that run once see only one scope. drizzle/relations misfires in commit hooks. Cloudflare types-fresh looks for the wrong file.

The rest are code fallbacks that repeat (and contradict) manifest defaults, and finding messages that state the rule instead of the problem. The slice also has a hand-written copy of `walkRoot`, three copies of a regex escape, and names that break the verb table (`setName`, `named`, `said`, `linted`, `tested`).
