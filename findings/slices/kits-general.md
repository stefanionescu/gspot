# Kits: General

The review read all 64 non-rule files in the 15 general kits. 32 of them have new findings. The main patterns are these. Some tool options in generated files cancel each other: lychee's offline setting, gitleaks' CSV pattern and allowlist floor, and the ec file list. Some settings never take effect: the Swift and SQL naming ceilings, `licenses.json`, and 34 acronym exceptions. Some help and summary text does not match the code, and some defaults are the house style of gspot.

**Corrections to the first pass:**
