# Kits: JavaScript, TypeScript, CSS, HTML, and Markdown

The review read all 16 non-rule files in the five kits. 14 of them have new findings.

The main patterns are these. The ESLint template piles three full presets on top of hand-picked rules, so many defects are reported two or three times. Several generated settings are dead or wrong for common projects. They include Node.js globals everywhere, a jsconfig with no JSX support, stylelint ignore globs that match nothing, and a markdownlint file nothing reads. Some summaries, comments, and help lines describe behavior the code does not have.

Paths are relative to `packages/cli/`. Every tool claim marked "verified" was checked against the installed package in `.gspot/node_modules` or by a run in the scratchpad.
