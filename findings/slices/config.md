# The Config Constants

`packages/cli/src/config` holds 68 TypeScript files with 616 exported constants, plus `eslint-levels.json` (1,577 entries). About 150 constants have a finding below that the first audit does not already list.

The main patterns are these. Fallbacks repeat a manifest default and never run, and two of them disagree with it. Tables restate a zod enum or another table. Some lists are dead or never change a result (`REFUSED_REASONS`, `HOST_ONLY`, three `PATH_TOKEN_SKIPS` entries). Some regular expressions and value tables give wrong results (`tsx` fences, migration versions, the `ansi` dialect, Git hook names). Paths below are relative to `packages/cli/src`.
