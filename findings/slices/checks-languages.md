# Checks: Languages

The review read all 44 files in `packages/cli/src/checks/language`. Of these, 40 have new findings.

The hand-written shell scanning has real bugs: any `#` starts a comment, quotes are ignored when counting arguments, and one-line functions lose their calls. Trivial-function checks report every Python lambda and Swift closure. Limit defaults are kept both in code and in the manifests. Every file writes the per-run cache and the "parser returned no tree" check by hand. Doc comments and finding messages say the wrong thing, or nothing a user can act on.

Paths are relative to `packages/cli/src/checks/language/` unless they start with `config/`, `types/`, `checks/`, `parsers/` (all under `packages/cli/src/`) or `kits/` (under `packages/cli/`).
