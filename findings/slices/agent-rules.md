# The Agent Rules

The review read all 86 rule files: 25 base files and 61 kit files. Paths below are relative to `packages/cli/`. 85 files have new findings, and only `NESTJS.md` has none.

The main patterns are these. Rules restate what a shipped check already reports, often at the same level. One rule appears in three to six files. Kit files carry the names of one project: an ML Python project, a chat app on Next.js and tRPC, a static site, Supabase, and gspot itself. Several rules contradict the shipped configuration, and many ask the agent for checks it cannot run.
