# Checks: General

The review read all 47 files in `packages/cli/src/checks/general`. Of these, 38 have new findings.

The main patterns are fallback constants that copy manifest defaults, and small helpers written two or three times. The repeated helpers are the folder of a path, path-token cleaning, parent-folder expansion, the Python package key, the allowed-folder test, and the harness folder set. Other patterns are names that hide what a value is (`said`, `shape`, `spawned`, `scanned`, `byPath`, `contractProperties`). The last pattern is finding messages that state the rule as if it described the file.

Paths below are relative to `packages/cli/src/checks/general/` unless they start with `packages/`, `config/`, `types/`, or another top-level `src` folder.
