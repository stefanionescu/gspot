# Carve-Outs

1 unresolved review record remains.

On October 6, 2026, the owner set a rule for the whole repository: one setting for each concern. Do not add a special time limit, a per-suite or per-OS budget, an environment switch, or an option that exists for one caller or one situation. When something is slow or special, fix the cause.

This rule overrides any proposal in the review files that keeps two settings for one concern. For example, the time-limit section of [the repository root review](repository-root.md#carve-outs) now keeps one per-test number for every suite and one job limit, as `review/carve-outs/001` says.

The carve-outs found on October 6, 2026 are listed in these sections:

- [Repository root: carve-outs](repository-root.md#carve-outs): time limits, CI job inputs, environment variables, registry workarounds.
- [Source layout: carve-outs](source-layout.md#carve-outs): tools named inline, `run_with === 'mise'` branches, Vale special paths, fixed deadlines, output limits, OS branches.
- [Tests in tests/cli: carve-outs](tests-cli.md#carve-outs): per-test limits, OS skips, harness options with one user.
- [Policy format: unneeded keys](policy-format.md#unneeded-keys): settings for one tool, one language, or one repository.
