# Tests: Tools, Plugin, Packages, and the Harness

6 unresolved review records remain.

A read-only review wrote these findings on October 6, 2026, against commit `3e1445a2d`. The Existing column names an older record that covers the same problem.

The worst problems, worst first:

1. 23 files in `tests/tools/configurations` paste the same 30-line table runner, and `react.test.ts` holds it three times. `tests/cli` has 9 more copies. Write it once, in one table test file per suite.
2. About 30 tests in `tests/tools` need no pinned executable tool. ESLint, Knip, Stylelint, and TypeScript come from `tests/node_modules`. 13 of them throw away the in-process ESLint that `createEslint` returns and start a hand-written Node script instead. Move them to `tests/cli` and use the instance they already have.
3. Seven tests copy `<checkout>/.gspot/node_modules/typescript`, which exists only after someone runs `gspot install` in this checkout. Commit 82bf7fcda says tests do not need that install. On a clean checkout these tests throw `ENOENT`.
4. Many installs are wasted. Both install sandboxes install, and then the test installs again. Semgrep is installed 11 times per run. Whole repositories are installed for single ESLint rules that `tests/cli` already covers in-process (react, expo, react-native, zod, no-debugger, html).
5. Some tests download from npm when they do not need to: vue, `html-validate` (8 installs), and `editorconfig-checker` inside the "isolated" registry.
6. Copy-paste constants: 14 hand-made init argument lists, about 150 `[agent_rules] enabled = false` literals, 6 hard-coded tool versions, and about 180 per-test timeouts equal to the suite default.
7. Some tests check removed code (retired worker files, removed Semgrep findings). Some test third-party tools: Prettier, TypeScript's own `@ts-` directives, and the `eslint-config-prettier` CLI. One test pins a double report for `process.exit` that the overlap policy says must not happen.
8. Flakes: the cause of the Windows "typescript in a scope" flake is not fixed. The time limit was raised and Defender was turned off instead. The launcher test still pins full check lists. The cancellation marker race was fixed twice, in two different styles.
9. Banned words (`fixture`, `rendered`, `synced`, `resolved`) appear in 29 local names. The naming check does not see local bindings.
