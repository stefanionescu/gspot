# Configurations and the ESLint Plugin

9 unresolved review records remain.

A read-only review wrote these findings on October 6, 2026, against commit `3e1445a2d`. The Existing column names an older record that covers the same problem.

Reviewed at HEAD 3e1445a2d (2026-10-06): all 56 `manifest.toml` files, all 85 agent rule files, every Eta source, style, and data file under `packages/cli/configurations/`, and every source file of `packages/eslint-plugin/`.

- `gspot/instances-in-registry` is on in every level-`all` ESLint config gspot writes, but it gets no `files` option, so it reports nothing unless a repository sets `files` through `tools.eslint.rules`.
- `gspot/import-direction` rebuilds what `eslint-plugin-boundaries` already does. The same configuration installs that plugin and configures it in the same generated file.
- Several Eta sources hand-list rules that the tool already groups. `ruff.toml.tmpl` lists 727 codes one per line. `basedpyrightconfig.json.tmpl` sets mode `off` and then lists 95 `report*` keys, although basedpyright ships `recommended` and `all` modes. `stylelint.json.tmpl` copies about 80 rule names from a preset it also extends.
- The manifest format has dead parts. `alternatives_checked` (25 uses) is never read. `off_values` is never set, so `disabledRuleProblems` never fires. `borrowed_checks` has one use, and it borrows a check that always runs anyway.
- The manifest format also has dead lines: 29 `runs = "files"` and 27 `kinds = ["source"]` lines only repeat the default, and 12 `requires` entries point at configurations every scope already gets.
- Vale at level `all` downloads 7 style packages and then turns off 95 of their rules. That includes 29 of the 47 Microsoft rules and 26 of the 37 Red Hat rules, mostly because "Google reports the same."
- Six tools are declared in two or three configurations with different fields, and nothing checks that the copies agree. The `shellcheck` copy in the actions configuration has no suppression marker. The Supabase CLI is the only installable tool with no pinned version.
- `no-trivial-functions` misses arrow functions written in a ternary branch. Two of the four suppressions of that rule in this repository exist only because of this bug.
- The agent rules still repeat checks word for word: React Native, NestJS, Postgres, Bash, Supabase, Zod, and Vue. One configuration's agent rule also contradicts its own default (nginx). The same sentences appear in three framework rule files.
- The word "configuration" means three things: the selectable unit, a generated tool file (`[[config]]`), and the `config/` folder. A manifest holds both `[configuration]` and `[[config]]`; review/glossary/001 renames the second to `[[tool_file]]`.
