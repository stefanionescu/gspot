# Glossary

One name for each concept, and one concept for each name. When a finding names something differently, this list
wins. When the renames are done, this table moves into `AGENTS.md`, and this file goes.

## One vocabulary

How to read the table:

- "The one name" is the name to use from now on. "Names to retire" lists every other name found for the same
  concept. "Where it applies" says where the name is used, and which report chose it when reports disagreed.
- Official names of external tools, formats and APIs stay as their owners spell them. Examples: ESLint
  "rule", "preset" and "overrides"; npm "workspace"; Git "staged", "fetch" and "index"; Vale's `vale sync`
  and "alert"; Apple "asset catalog"; SPDX "license exception"; GitHub "runner image"; Postgres "policy";
  the `packageManager` field of package.json; the library name `swift-snapshot-testing`.
- Every new code name in this table was split into words and checked against the shipped banned groups
  (`packages/cli/configurations/general/naming/policy.json`, which becomes `naming/defaults.json`) and this
  repository's banned words (`naming.banned`, which becomes `naming.banned_words`). That check is why code says
  `NpmClient` where text says "package manager" ("manager" is banned), and why shared test code is
  `tests/setup/`, not `tests/helpers/` ("helpers" is a banned folder word).
- The table names only what exists after the cleanup. A name in "Names to retire" must not come back.
