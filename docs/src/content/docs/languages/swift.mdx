gspot checks Swift packages and Xcode projects. SwiftLint and SwiftFormat run before each commit. Before each push, gspot
builds the package or the Xcode scheme, finds declarations that nothing uses, and measures test coverage:

To limit which module may import which, see [Import rules](/configure/import-rules/#swift).

## Before you start

Install the Swift toolchain, then install gspot with mise, as the [Quickstart](/start/quickstart/) shows. With an Xcode
project, the build and coverage checks need macOS, with Xcode chosen through `xcode-select`. `swift/periphery`,
`swift/swiftlint-analyze`, and `xcode/plutil` run only on macOS.

## Xcode projects

`gspot init` writes the Xcode project, scheme, and destination that it finds into `gspot.toml`. To set them yourself:

```toml title="gspot.toml"
[swift]
xcode_project = "App.xcodeproj"
xcode_scheme = "App"
xcode_destination = "generic/platform=iOS Simulator"
```

When `gspot.toml` sets `swift.xcode_project`, the build, Periphery, analyzer, and coverage checks use that project or
workspace. The `xcode` configuration also checks property lists, string catalogs, asset catalogs, unused assets, Swift
files that no target lists, the App Transport Security settings, and the entitlements against
`xcode.allowed_entitlements`.

## Analyzer

`swift/swiftlint-analyze` runs the SwiftLint analyzer on the build log, and only when you name it:

```shell
gspot check --only swift/swiftlint-analyze
```

When the analyzer reports an unused import that your code needs, list that import in `swift.allowed_unused_imports`.

## Lint rules in test folders

gspot writes a `.swiftlint.yml` into each `Tests` or `*Tests` folder, which turns off `force_unwrapping` and
`no_magic_numbers` in tests. When an editor extension passes `--config` to SwiftLint, SwiftLint ignores these
test-folder files, so set the extension to run SwiftLint without `--config`.

## Coverage

To set a minimum line coverage for one Swift target, write a `[[coverage.swift_target]]` record by hand:

```toml title="gspot.toml"
[[coverage.swift_target]]
name = "Orders"
min_line_percent = 80
```

`name` is a target in the coverage report. When `min_line_percent` is lower than `coverage.min_line_percent`, add a
`reason`. Then run `gspot install` and `gspot check --only swift/tests`.
