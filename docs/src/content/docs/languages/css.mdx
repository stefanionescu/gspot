gspot checks style sheets, and the style blocks inside Vue, Svelte, and Astro components, with Stylelint. Its options

## Component styles

Stylelint also checks the style blocks of Vue, Svelte, and Astro components, through the `postcss-html` parser that the
`css` configuration installs. Each kind of component keeps its own selectors, such as `:deep` and `:slotted` in Vue,
and `:global` in Svelte and Astro.

Tailwind directives and `theme()` need a `tailwindcss` dependency in the nearest npm project.

Value checks skip declarations that contain `theme()` or the Vue `v-bind()`. Variables inside `v-bind()` keep their
case, but CSS keywords need lowercase letters.

## CSS module files

In `*.module.css` files, Stylelint accepts the `composes` property and the `:global`, `:local`, `:export`, and
`:import` selectors of CSS Modules.
