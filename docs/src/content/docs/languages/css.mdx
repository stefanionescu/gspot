gspot checks style sheets, and the style blocks inside Vue, Svelte, and Astro components, with Stylelint. gspot writes
the Stylelint options from `gspot.toml`, and [Lint rules](/configure/lint-rules/#stylelint) shows how to change them.

## Component styles

Stylelint reads the style blocks of Vue, Svelte, and Astro components with the `postcss-html` parser, which the `css`
configuration installs. Stylelint accepts the special selectors of each kind of component, such as `:deep` and
`:slotted` in Vue, and `:global` in Svelte and Astro.

Tailwind directives and `theme()` need a `tailwindcss` dependency in the nearest npm project.

The checks of CSS values skip declarations that contain `theme()` or the Vue `v-bind()`. Variable names inside
`v-bind()` can use any case, but CSS keywords must be lowercase.

## CSS module files

In `*.module.css` files, Stylelint accepts the `composes` property and the `:global`, `:local`, `:export`, and
`:import` selectors of CSS Modules.
