## Dialect

SQLFluff parses the dialect that `sql.dialect` names, `ansi` by default, so set it to your database, such as `postgres`,
`mysql`, or `sqlite`:

```shell
gspot set sql.dialect postgres
```

The [`postgres` configuration](/reference/configurations/postgres/) sets it for you. SQLFluff reads each file as plain SQL,
and does not expand Jinja or other templates.

When one folder holds another dialect, such as SQLite migrations beside a Postgres database, set the dialect in the
[scope](/configure/monorepos/#settings-in-a-scope) of that folder:

```toml
[[scope]]
path = "d1"
sql.dialect = "sqlite"
```

`naming/identifiers` reads SQL names with a Postgres parser. Under a dialect other than `postgres`, which includes
the default `ansi`, it checks the files that this parser can read, and reports no `syntax` finding for the others.

## Style

Keywords, literals, and types are upper case, and identifiers and functions are lower case, so
`select id from user_accounts;` gets a `CP01` finding for each lowercase keyword.

SQLFluff takes its line length from `format.print_width`, and its indent from the `format` settings of SQL files. When
the rest of your repository uses another indent, `gspot init` writes a `[[format.override]]` record that indents SQL
files by four spaces, and you change the SQL indent in that record.

## Levels

At level `basic`, gspot turns off six SQLFluff rules about joins, casts, subqueries, and `LIMIT`: `AM05`, `AM09`,
`CV11`, `ST05`, `ST07`, and `ST09`. Level `all` runs them.

## Old settings and ignores

`gspot init` deletes `.sqlfluff` and `.sqlfluffignore`, because gspot reads only the SQLFluff settings that it writes, and
`sql.dialect` and `format` are the only settings it has for them. A SQLFluff table in `pyproject.toml`, `setup.cfg`, or
`tox.ini` stays, and `gspot/conflicting-configs` reports it until you delete it.

To turn one rule off, ignore it with a reason, or allow one statement with a comment, such as
`SELECT * FROM orders -- noqa: AM04 -- reason: the view mirrors every column`:

```shell
gspot ignore sql/sqlfluff --rule AM04 --reason "The reporting views mirror every column of their table."
```
