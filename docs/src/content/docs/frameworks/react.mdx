## When gspot turns it on

gspot turns on `react` in a scope whose `package.json` depends on `react`, and `react-dom` when it depends on
`react-dom`. The [Next.js](/frameworks/nextjs/), [React Native](/frameworks/react-native/), and
[Expo](/frameworks/expo/) configurations also turn on `react`. React sources get the browser globals, as
[JavaScript runtimes](/languages/javascript-typescript/#javascript-runtimes) describes.

## ESLint rules of `react`

`javascript/eslint` checks the `.js`, `.jsx`, `.ts`, and `.tsx` files of the scope with these rules:

- The `recommended` presets of `@eslint-react/eslint-plugin` and eslint-plugin-react-refresh, and the
  `recommended-latest` preset of eslint-plugin-react-hooks.
- `@eslint-react/dom-no-dangerously-set-innerhtml`, `@eslint-react/no-unstable-context-value`, and
  `@eslint-react/no-unstable-default-props`.
- At level `all`: `@eslint-react/no-array-index-key`, `@eslint-react/no-missing-component-display-name`,
  `@eslint-react/use-state`, and the naming rules for contexts, IDs, and refs.

At level `all`, the `gspot/restricted-syntax` rule also reports the `FC` type, with the message "Declare the props type
on the parameter instead of FC."

## ESLint rules of `react-dom`

`react-dom` adds the `recommended` preset of eslint-plugin-jsx-a11y-x, which checks labels, alternative text, keyboard
access, and Accessible Rich Internet Applications (ARIA) attributes.

## Matching versions

React stops at run time when `react` and `react-dom` differ, so before each commit, `react-dom/react-versions` checks
that they resolve to the same version. It reads the lockfile of the scope, or the version ranges of `package.json` when
no lockfile exists:

```text
failed   react-dom/react-versions  1 finding
  package.json:1  react-versions  react 19.1.0 and react-dom 19.0.0 differ, and React stops at run time when they do. Install the same version of both.
```

## What gspot accepts

`eslint-plugin-react-hooks` reports the hook mistakes, so gspot turns off the `@eslint-react` rules that report the same
ones under other names, such as `@eslint-react/rules-of-hooks` and `@eslint-react/exhaustive-deps`.

At level `all`, gspot reports a small private function that at most one place uses, and a file that only forwards to
another module. In `.jsx` and `.tsx` files, a short component passes both rules. The naming checks of that level accept
a file name in PascalCase or kebab-case in these files. They also accept PascalCase for a component function, and for a
variable that holds a component.
