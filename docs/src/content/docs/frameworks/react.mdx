React apps in the browser, and runs one check:

React sources get the browser globals, as [JavaScript runtimes](/languages/javascript-typescript/#javascript-runtimes)
describes.

## ESLint rules of `react`

`javascript/eslint` runs the `recommended` presets of `@eslint-react/eslint-plugin` and eslint-plugin-react-refresh, and
the `recommended-latest` preset of eslint-plugin-react-hooks. It also reports `dangerouslySetInnerHTML`, unstable context
values, and unstable default props.

Level `all` adds rules for array index keys, component display names, and the names of `useState` values, contexts, IDs,
and refs. It also reports the `FC` type, with the message "Declare the props type on the parameter instead of FC."

## ESLint rules of `react-dom`

`react-dom` adds the `recommended` preset of eslint-plugin-jsx-a11y-x, which checks labels, alternative text, and keyboard
access.

## Matching versions

React stops at run time when `react` and `react-dom` differ, so before each commit, `react-dom/react-versions` checks
that they resolve to the same version. It reads the lockfile of the scope, or the version ranges of `package.json` when
no lockfile exists:

```text
failed   react-dom/react-versions  1 finding
  package.json:1  react-versions  react 19.1.0 and react-dom 19.0.0 differ, and React stops at run time when they do. Install the same version of both.
```

## What level `all` accepts

Level `all` reports a small private function that at most one place uses, and a file that only forwards to another
module. A short component in a `.jsx` or `.tsx` file passes both rules. The naming checks accept a file name in PascalCase
or kebab-case in these files, and PascalCase for a component function and for a variable that holds a component.
