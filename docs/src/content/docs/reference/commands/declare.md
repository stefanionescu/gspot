Say what a path is: generated by a command, or vendored.

```text
gspot declare [options] <glob...>
```

## Arguments

| Argument | Meaning  |
| -------- | -------- |
| `glob`   | required |

## Options

| Flag                      | Meaning                                       |
| ------------------------- | --------------------------------------------- |
| `--produced-by <command>` | The command that regenerates the files        |
| `--vendored`              | Upstream source kept in the tree              |
| `--reason <text>`         | Why; required for vendored paths              |
| `--remove`                | Delete the matching entry instead             |
| `--dry-run`               | Print what would be written and write nothing |
