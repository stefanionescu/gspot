---
title: "gspot completion"
description: "Print the shell completion script for bash, zsh, fish, or powershell"
---

Print the shell completion script for bash, zsh, fish, or powershell.

```text
gspot completion [options] <shell>
```

## Arguments

| Argument | Meaning                          |
| -------- | -------------------------------- |
| `shell`  | Shell type for completion script |
