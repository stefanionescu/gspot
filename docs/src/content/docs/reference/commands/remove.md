---
title: "gspot remove"
description: "Remove a preset from the root selection, or from one scope"
---

Remove a preset from the root selection, or from one scope.

```text
gspot remove [options] <preset>
```

## Arguments

| Argument | Meaning  |
| -------- | -------- |
| `preset` | required |

## Options

| Flag             | Meaning                                       |
| ---------------- | --------------------------------------------- |
| `--scope <path>` | The scope to remove it from                   |
| `--dry-run`      | Print what would be written and write nothing |
