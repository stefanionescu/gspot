---
title: "gspot add"
description: "Add presets to the root selection, or to one scope"
---

Add presets to the root selection, or to one scope.

```text
gspot add [options] <preset...>
```

## Arguments

| Argument | Meaning  |
| -------- | -------- |
| `preset` | required |

## Options

| Flag             | Meaning                                       |
| ---------------- | --------------------------------------------- |
| `--scope <path>` | The scope to add them to                      |
| `--dry-run`      | Print what would be written and write nothing |
