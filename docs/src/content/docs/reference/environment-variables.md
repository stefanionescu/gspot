---
title: Environment variables
description: The environment variables that change what gspot does.
---

| Variable       | Purpose                                                                                                         |
| -------------- | --------------------------------------------------------------------------------------------------------------- |
| `GITHUB_TOKEN` | Lets gspot read a template from a private GitHub repository. mise also reads it for tool downloads from GitHub. |
| `NO_COLOR`     | Any nonempty value turns color off.                                                                             |

The [Commands](/reference/commands/#exit-codes) page lists the exit codes of every command.
