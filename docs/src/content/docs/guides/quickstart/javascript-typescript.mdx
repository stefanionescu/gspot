## Set up the tools

<Code code={`${example.commands.init}\n${example.commands.level}\n${example.commands.install_tools}`} lang="sh" />

`init` selects TypeScript, JavaScript, and Markdown and writes `gspot.toml` and the tool files under `.gspot/`.
`set level all` turns on more checks, including the ones for files and functions that only pass calls on.
`install` installs the tools for that level and turns on the hooks that `init` proposes.

To scan dependency licenses, list allowed licenses first. See [Dependency licenses](/guides/dependency-licenses/).

## Try the hook

Before fixing the source, you can stage the files and try to commit them:

<Code code={`git add -A\ngit commit -m "${example.agent.message}"`} lang="sh" />

The hook refuses the commit and reports the findings. After you fix them, the hook can pass.
