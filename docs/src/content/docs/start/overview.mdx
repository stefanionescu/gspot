## What it flags

Each item names the mistakes of coding agents that gspot catches.

- Bugs and type errors: a call to a function that the project does not have, or a promise that nothing waits for
- Security and accessibility problems, and leaked secrets: an API key in a source file, a query built from user input,
  or a button without a label
- Vulnerable dependencies and licenses that you do not allow: a package added from memory, at an old version
- Formatting, broken links, and spelling: a link to a page that does not exist, or files in a style that the project
  does not use
- Lint rules turned off without a reason: a suppression comment that hides a finding instead of fixing it
- At level `all`: the stricter checks that [Levels](/start/concepts/#levels) lists

To see what gspot finds in your repository, run `npx @gspothq/cli scan`. It works on a copy, so your repository does
not change.
